# Virtual Stock Market — Prices Live Update

A production-ready **paper trading simulator** for forex and gold, built with Next.js 14, OANDA live pricing, TradingView chart integration, and four AI-powered features via the Claude API.

## Features

- **Live Market Data** — Real-time bid/ask prices from OANDA for XAUUSD, EURUSD, GBPUSD, USDJPY and more
- **Paper Trading Engine** — Execute BUY/SELL orders with virtual funds, position tracking, and P&L calculation
- **TradingView Charts** — Embedded live charts with multiple timeframes
- **TradingView Webhook** — HMAC-verified signal ingestion from your Pine Script indicators
- **AI Trade Journal** — Claude-powered critique of every closed trade with ICT/SMC concept detection and a quality score (−100 to 100)
- **AI Signal Confidence** — Contextual confidence notes on incoming signals based on historical win rate
- **AI Macro Briefing** — Daily pre-market economic briefing generated by Claude and cached in the database; refreshed automatically via Vercel cron at 06:00 UTC
- **AI Risk Coach** — Behavioral pattern detection (revenge trading, overtrading, position-size creep) with actionable alerts

## Tech Stack

| Layer | Technology |

## Getting Started

### 1. Clone and install

```bash
git clone https://github.com/SaiVatsal/Virtual-Stock-Market-Prices-Live-Update.git
cd Virtual-Stock-Market-Prices-Live-Update
npm install
```

### 2. Configure environment variables

Copy `.env.example` to `.env` and fill in your credentials:

```bash
cp .env.example .env
```

| Variable | Where to get it |
|---|---|
| `DATABASE_URL` | Supabase → Settings → Database → Connection string (with `?pgbouncer=true`) |
| `OANDA_API_KEY` | OANDA fxTrade Practice → Manage API Access |
| `OANDA_ACCOUNT_ID` | OANDA Dashboard → Account number |
| `ANTHROPIC_API_KEY` | [console.anthropic.com](https://console.anthropic.com) |
| `TRADINGVIEW_WEBHOOK_SECRET` | Any random string — used to verify TV webhooks |
| `CRON_SECRET` | Any random string — used to authenticate Vercel cron calls |

### 3. Push the database schema

```bash
npm run db:push
```

### 4. Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## TradingView Webhook Setup

In your Pine Script indicator, add an alert and set the webhook URL to:

```
https://your-app.vercel.app/api/webhooks/tradingview
```

Add the header `x-tradingview-signature` containing an HMAC-SHA256 of the request body using your `TRADINGVIEW_WEBHOOK_SECRET`.

## Deploying to Vercel

```bash
vercel deploy
```

Set the same environment variables in the Vercel dashboard. The macro briefing cron job (`0 6 * * *`) is defined in `vercel.json` and runs automatically on Vercel.
